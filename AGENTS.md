# AGENTS.md

Coffice is an AI-first office suite: LibreOffice rendering core bridged to an LLM agent via a Python MCP server (`mcp` 1.x, FastMCP API) and the external `co` CLI for Git-style document snapshots. Route 1 MVP scope and full integration details live in `docs/route1.md`; read it before touching core/versioning.

## Setup & commands

```sh
make setup          # .venv + `pip install -e ".[dev]"` (uv preferred) + `npm --prefix ui install`
make lint           # ruff check src tests
make test           # .venv/bin/python -m pytest  (pytest config in pyproject.toml)
make ui-test        # vitest in ui/
make build-oxt      # builds dist/Coffice.oxt from extension/
make smoke          # end-to-end; SKIPS (exit 0) when LO/co are absent
```

- Must run `make setup` first: tests rely on the editable install so `import coffice` resolves under `src/`.
- Single test: `.venv/bin/python -m pytest tests/mcp/test_registry.py::test_name`.
- CI (`.github/workflows/ci.yml`) runs exactly: `uv run ruff check src tests` → `uv run pytest` → `npm --prefix ui ci/build/test` → `bash extension/build.sh` → `bash scripts/smoke_route1.sh`. Mypy is configured but not run anywhere — do not add it to gates.
- Releases: semantic-release on push to `main`, so Python-facing commit messages must follow Conventional Commits.

## Architecture (monorepo in one package)

Python package `coffice` under `src/coffice/` (editable-installed), plus the React UI in `ui/`:

- `core/` — soffice headless lifecycle (`lo_manager.py`) + Document/PyUNO wrapper (`document.py`), diff projector. Requires LibreOffice/PyUNO at runtime.
- `mcp/` — MCP server, tool registry, tools_read/write/version, middleware.
- `versioning/` — `co` CLI wrapper + `.co-bundle` export/import.
- `governance/` — agent identity, permissions, guardrails, audit log.
- `agent/` — LLM orchestration loop + HTTP facade (`agent_api.py`).
- `sidebar/` — LO extension hosting contract (single source of truth).
- `ui/` — React 18 + Vite + TS + Vitest "Agent Deck".

Entrypoints: `.venv/bin/python -m coffice.mcp.server`, `.venv/bin/python -m coffice.agent.agent_api`.

## Gotchas

- **`mcp` is pinned `>=1.0,<2.0`** in `pyproject.toml` — the code uses the FastMCP `mcp.run(transport="stdio")` API; 2.x is incompatible. Do not bump.
- **Never edit `extension/python/coffice/*.py`** — they are generated by `extension/build.sh` from `src/coffice/sidebar/` (also `extension/icons/coffice.png`). Edit the source under `src/coffice/sidebar/` and rebuild.
- **LO-dependent tests skip, not fail**: `tests/core/` and `tests/mcp/test_integration.py` gate on `LO_UNAVAILABLE` from `core/lo_manager.py`. Test in a fresh env without LO and the whole suite must still pass with skips.
- **MCP unit tests use fakes**: `tests/mcp/conftest.py` swaps the document factory for `FakeDocument`, the co client for `FakeCoClient`, and injects `FakeProjector` — keep new tool tests on this pattern instead of requiring live LO/co.
- PyUNO ships with LibreOffice (`apt install libreoffice python3-uno`); it is not pip-installable. Nothing fails at import time when LO is missing.
- `smoke` and CI must not hard-require LO or `co` — they probe and skip gracefully.

## Key env vars (defaults in `docs/route1.md` §1.4)

`COFFICE_LLM_BASE_URL`/`MODEL`/`API_KEY` (OpenAI-compatible), `COFFICE_DOC_PATH` (doc the agent opens), `COFFICE_LO_PORT` (UNO socket, default 2002), `COFFICE_AUDIT_LOG`, `COFFICE_WRITE_RATE_LIMIT` (default 30/min), `COFFICE_AGENT_PORT` (8790), `COFFICE_UI_PORT`/`COFFICE_UI_URL` (Agent Deck, 8787), `CO_BIN` (co binary path; probed from `CO_BIN` → `PATH` → `~/.local/bin/co`).

## Style

- Ruff: `line-length = 100`, lint set `E,F,W,I,UP,B` (target py311). Run `make lint` after edits; format/imports must pass.
- Python requires `>=3.11`; use `from __future__ import annotations` and modern typing consistent with the codebase.
- UI has a `typecheck` script (`tsc -b --noEmit`) — run it after TS changes; `npm run build` includes it.
- **Write all commit messages and code comments in English**, never in Chinese or other languages.
